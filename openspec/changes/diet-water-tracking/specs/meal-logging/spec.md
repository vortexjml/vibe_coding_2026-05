## ADDED Requirements

### Requirement: 식단 기록 입력
사용자는 음식명, 칼로리, 단백질, 탄수화물, 지방을 입력해 날짜별 식단을 SHALL 기록할 수 있다.

#### Scenario: 식단 항목 추가
- **WHEN** 사용자가 음식명과 칼로리를 입력하고 저장하면
- **THEN** 해당 항목이 오늘 날짜의 식단 목록에 추가되어야 한다

#### Scenario: 음식명 미입력 저장 시도
- **WHEN** 음식명 없이 저장 버튼을 누르면
- **THEN** 저장되지 않고 "음식명을 입력해주세요" 안내가 표시되어야 한다

#### Scenario: 식단 항목 삭제
- **WHEN** 사용자가 특정 식단 항목의 삭제 버튼을 누르면
- **THEN** 해당 항목이 목록에서 제거되어야 한다

### Requirement: 날짜별 식단 합계 표시
오늘 기록한 식단의 총 칼로리, 단백질, 탄수화물, 지방 합계를 SHALL 표시한다.

#### Scenario: 합계 자동 계산
- **WHEN** 식단 항목이 하나 이상 존재하면
- **THEN** 페이지 상단에 총 칼로리(kcal) 및 3대 영양소 합계가 표시되어야 한다

#### Scenario: 기록 없음 상태
- **WHEN** 오늘 식단 기록이 없으면
- **THEN** "아직 식단 기록이 없어요" 빈 상태 메시지가 표시되어야 한다
