## ADDED Requirements

### Requirement: 커스텀 종목 추가 진입점
종목 선택 바텀시트는 "직접 추가" 버튼을 SHALL 제공한다.

#### Scenario: 직접 추가 버튼 표시
- **WHEN** 사용자가 루틴 편집에서 종목 추가 바텀시트를 열면
- **THEN** 기존 검색/필터 영역 상단 또는 하단에 "직접 추가" 버튼이 표시되어야 한다

### Requirement: 커스텀 종목 입력 폼
"직접 추가" 진입 시 종목명, 근육군, 장비를 입력할 수 있는 폼을 SHALL 표시한다.

#### Scenario: 필수 필드 입력
- **WHEN** 사용자가 종목명을 입력하고 근육군과 장비를 선택한 뒤 저장하면
- **THEN** 해당 종목이 IndexedDB에 저장되고 종목 목록에 즉시 나타나야 한다

#### Scenario: 종목명 미입력
- **WHEN** 종목명 없이 저장하면
- **THEN** 저장되지 않고 "종목명을 입력해주세요" 안내가 표시되어야 한다

### Requirement: 저장 후 즉시 루틴에 추가
커스텀 종목 저장 직후 해당 종목이 루틴에 바로 추가되어야 한다.

#### Scenario: 저장 후 자동 추가
- **WHEN** 커스텀 종목 저장이 완료되면
- **THEN** 바텀시트가 닫히고 새 종목이 루틴 종목 목록에 추가된 상태여야 한다
